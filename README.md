# FUW Student Skilled Link

A responsive, browser-based student talent marketplace for Federal University Wukari and the Wukari community.

## Run locally
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser, or use VS Code Live Server.
3. An internet connection is needed for the Tailwind CSS CDN, Font Awesome icons, and Google Fonts.

## Included files
- `index.html` — application structure and screens
- `style.css` — responsive visual styling and interaction polish
- `app.js` — directory, job board, matcher, bookings/contracts, registration, and local storage logic

## Notes
- Demo listings are sample data.
- Data is stored in the browser's local storage; it is not shared between devices or browsers.
- The app is a front-end demo and does not include a server/database or real identity verification.
